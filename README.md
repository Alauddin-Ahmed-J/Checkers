Checkers

A simple command-line Checkers game written in C++.

This project was built as a learning exercise to practice game programming fundamentals, game logic, and implementing a basic AI opponent.

Features

- Standard 8×8 checkers board
- Player vs AI gameplay
- Piece movement and captures
- Multiple captures in a single turn
- King promotion
- Win and stalemate detection
- Simple AI that generates all legal moves and selects one at random

Concepts Practiced

- 2D arrays
- Functions
- Structs
- Conditional logic
- Loops
- Game state management
- Basic AI move generation
- Random number generation
- Input validation

Purposeo

This project is part of my journey learning C++ by building practical applications instead of only solving programming exercises. The main goal was to understand how turn-based games work, how game rules can be implemented in code, and how to create a simple AI capable of making legal moves.
